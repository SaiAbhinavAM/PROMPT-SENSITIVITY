Which rhetorical dimension an instruction uses — question-form, theme-isolation, output-format, and so on — drives prompt sensitivity far more than the coarse Pool A/B split we originally hypothesised. What problem are we studying?

Prompt sensitivity

LLMs give inconsistent outputs when a prompt is reworded but its meaning is preserved. That fragility undermines reproducibility and trust. We ask: is this fragility random, or is it structured by the style of instruction?

Our clean definition

Sensitivity = spread of a cell's outputs. Quality = mean. We keep the two strictly separate so a prompt can't look "sensitive" just because it's low-quality.

A cell = one (article, seed) → its ~6 meaning-equivalent paraphrase outputs.

Main finding — Llama-3.1-8B

Dimension is the primary axis. Instruction dimension explains 19.3% of sensitivity variance vs just 1.7% for the Pool A/B split (~11×). Mixed-effects test sensitivity ~ dimension + (1|seed) + (1|article): χ² = 30.8, p = 0.0036. The Pool A/B split is not significant (Mann-Whitney p = 0.16).

Honest qualifier: the effect is strong in Llama but weaker/borderline in Qwen (assumption-free permutation p = 0.071). Only the coarse ranking replicates — the exact 14-way order is model-specific.

The critical caveat (we report it honestly)

The 0.70 replication is in direction/ranking, not strength. Under strict assumption-free tests Qwen's dimension effect does not clear significance:

  • Qwen permutation p = 0.071 (borderline); seed-Kruskal p = 0.156.
  • Significant only in the parametric mixed model (p = 0.019).
  • Llama, by contrast, passes the permutation test (p = 0.022).
  • Excluding the ~4.5% degenerate/refusal cells did not rescue it (0.071 → 0.066) — the weakness is intrinsic.

So effect strength is model-dependent: strong in Llama, borderline in Qwen.

Methodology in brief

Design

  • Crossed grid: every seed applied to the same 30 CNN/DM articles (instance-fixed, prompt-varied) — POSIX / ProSA / PromptBench convention.
  • Decoding: greedy (temperature 0), to isolate the prompt effect from sampling noise.
  • Paraphrase equivalence validated by bidirectional NLI entailment, not just similarity.

Sensitivity composite (v2), rank-normalized within a run

0.25·SMS-drift + 0.20·ROUGE-L-var + 0.15·CS-cv + 0.15·faith-cv + 0.125·PPL-var + 0.125·PC-stab-cv

Spread of bounded quality scores is level-normalized (coefficient of variation) to de-confound spread from quality level; lexical drift (ROUGE-L) keeps the score from being purely embedding-based.

Honest limitations & what's next

Limitations we're not hiding

  • Effect strength is model-dependent — strong in Llama, borderline in Qwen.
  • Only the coarse pattern replicates; the exact 14-way order is model-specific.
  • Thin dimensions — Meta-reflection = 1 seed; several have only 3.
  • Narrow slice — two 7–8B models, one task, one dataset; no 70B, no non-summarization task.
  • Post-hoc pivot — the pre-registered Pool A/B hypothesis failed; dimension emerged from the data.
  • No human validation of the drift metric yet (face validity only).

Recommended next steps

  • A third model (highest value) — resolves whether Qwen's weakness is an outlier or the effect is genuinely fragile. Mistral-7B (new family) or Llama-3.1-70B (scale contrast).
  • Balance thin dimensions — add seeds so no dimension rests on a single prompt.
  • ~50-pair human validation of the drift metric.
  • Format/surface perturbations as a second axis, or scope the paper explicitly to semantic-paraphrase sensitivity.
Defensible claim for the write-up: Across two model families, instruction dimension drives prompt sensitivity far more than the Pool split (both mixed-model p < 0.02, ~11–18× more variance), and the dimension rankings agree significantly (Spearman 0.70, p = 0.005) with identical most/least-sensitive classes. Question-form & theme-isolation phrasings are reliably the most sensitive; format & constraint phrasings the least. Effect strength is model-dependent and the fine-grained ranking is model-specific — best described as a robust coarse pattern, not an exact cross-model law.
